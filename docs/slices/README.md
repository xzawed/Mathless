# Slices — 기능 단위 SPEC 색인

**슬라이스**는 이 저장소의 SDD 단위다: 하나의 기능을 표면 문법 → 타입체크 → IR → codegen →
바인딩 → 오라클 실측까지 세로로 관통해 끝내는 작업 묶음. 각 슬라이스는 **SPEC 먼저 → 사용자 확인 →
TDD 구현 → Grok 검증 → PR** 순서를 따른다(`CLAUDE.md` "개발 방법론").

## 여기 있는 것 vs `docs/phaseN/`에 있는 것

| 위치 | 무엇 | 왜 |
|------|------|-----|
| `docs/slices/SPEC-*.md` | **기능 슬라이스** SPEC (이 폴더) | 기능은 로드맵의 phase 경계를 따르지 않는다. 슬라이스는 표면 문법일 수도 ABI일 수도 있고, 대개 둘 다다 |
| [`docs/phase1/SPEC.md`](../phase1/SPEC.md) · [`WBS.md`](../phase1/WBS.md) | **phase(캠페인)** 계획 — 그 phase의 목표·수용 기준·작업 분해 | `ROADMAP.md`의 phase는 제품 캠페인(수직 슬라이스 / struct·import / DX / 두 번째 호스트)이지 SDD 단위가 아니다 |

`docs/lang/`이 아닌 이유: 다음 슬라이스들(D16 caller-allocates·context handle, 문자열·구조체
마샬링, 콜백)은 **언어가 아니라 ABI·메모리** 작업이다. `docs/lang/`은 즉시 `docs/abi/`를 함께
요구하게 된다. 이미 있는 D17도 언어이자 ABI다.

`docs/phase1.5/`가 아닌 이유: phase 번호는 다시 이름을 바꿔야 한다.

## 색인

> **이 표를 슬라이스마다 갱신한다.** 이 폴더가 그냥 쌓이기만 하면 옮긴 의미가 없다(Grok 지적).
> 현재 상태·다음 작업의 정본은 언제나 `docs/STATUS.md`.
>
> **각 SPEC은 작성 시점의 설계 기록이다.** 본문의 "BLOCKED"/"미검증" 같은 서술은 그때의 사실이며
> 현재값이 아니다. 상태를 알고 싶으면 `docs/STATUS.md`를 본다. **슬라이스가 닫히면 SPEC 머리에 기록
> 안내(`기록 문서다.`)를 달고 본문은 다시 고치지 않는다** — 현재 상태를 검사하는 가드도 SPEC 본문은 읽지
> 않는다(`a_closed_spec_says_so_in_its_own_header`, `is_record`).

## 다음 슬라이스 (SPEC 미작성)

> **반올림 내장 함수도 닫혔다**(위 색인, #83). 업무 규칙을 세 라운드 더 써 본 결과다 —
> 스칼라 로직은 전부 컴파일됐고, 벽은 **배열**(두 번)과 **반올림**이었다. 그때는 배열에 힙이
> 필요해 Q12가 선행한다고 봤으므로, 그동안 막을 수 있는 오답을 먼저 막았다.
> **(그 전제는 낡았다 — Q12는 #87에서 닫혔고 #92가 실제로 썼다. 게다가 2026-09-01 실측으로
> 배열 수요는 대부분 IN 방향이고, IN은 빌린 포인터+길이라 Q12를 쓰지 않는다.)**
>
> **`out` 파라미터도 닫혔다**(위 색인, #80). 다음 후보를 §7 방식으로 재 본 결과 `else`·`break`·
> 복합 대입은 **아프지 않았다** — 계층 수수료·등급 할인·연체 상한 규칙이 전부 조기 `return`과
> `let mut`로 컴파일된다. 다음 벽은 **데이터**다: 문자열·배열·struct.
>
> ✅ **그것을 막던 Q12는 2026-08-31에 닫혔다** — caller-allocates, 절단은 D17 음수 status
> (`DECISIONS.md` D16 파생 상세 · `HOST_ABI.md` "가변 길이 데이터"). 그러면서 범위가 갈렸다:
> **고정 레이아웃 struct(스칼라 필드만)는 힙이 필요 없어 Q12 밖**이고, 셋 중 가장 작은 슬라이스다.
>
> **`i32` 나눗셈·나머지는 닫혔다**(위 색인, #76). 그 슬라이스가 갚을 것으로 기대됐던
> **`&&` 단락 평가 부채(`STATUS.md` §5-1)는 갚지 못했다** — DP-D1이 전역 연산자로 결정돼
> 관측할 트랩이 남지 않았다. 근거는 `SPEC-i32-division.md` §5.2.
> → **그 부채는 2026-09-13에 닫혔다.** 갚은 것은 이 슬라이스가 아니라 **배열 입력(#200)**이다 —
> 범위 밖 인덱스가 **식 자리에서** `-2`를 반환하므로, 트랩 없이도 오른쪽 피연산자의 평가 여부가
> 호스트의 status에 보인다(`STATUS.md` §5-1·§9-37).

> ✅ **문자열 반환도 닫혔다**(위 색인, #92) — **Q12 프로토콜이 실제로 쓰였고 결함은 나오지 않았다.**
> 절단·probe·딱 맞음·빈 문자열·도메인 에러·음수 용량을 canary 버퍼로 전부 쟀다. 이제 배열이
> 그 프로토콜을 **검증된 상태로** 물려받는다 — 그것이 문자열을 먼저 둔 이유였다(SPEC §0.2).
> **남은 것은 표현력이다:** 연결·포맷이 있어야 실측된 R2·R6이 풀린다.
>
> ✅ **문자열 입력도 닫혔다**(위 색인, #89). 데이터 세 갈래 중 첫 번째다. 남은 둘의 순서는
> 바뀌지 않았다: **고정 레이아웃 struct**(가장 작고 Q12 밖, 그러나 실측 수요가 거의 0),
