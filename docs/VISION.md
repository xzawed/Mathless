# VISION

## 문제

Delphi/Object Pascal은 타입 안정성, 네이티브 성능, 구조적 문법에서 강하다.  
그러나 생태계가 닫혀 있고, 현대 개발자 유입이 적으며, 동적 확장·도구·AI 친화 경험이 TypeScript 수준에 못 미친다.

기존 스크립트 언어(Python, Lua, JS)는 유연하지만 타입과 배포 산출물 보호가 약하다.  
기존 Pascal Script/Inno Setup `[Code]`는 검증됐지만 현대 DX와 다중 호스트, 보호된 네이티브 배포를 목표로 설계되지 않았다.

## 비전

갈라파고스처럼 고립된 Delphi의 강점(타입, 네이티브, 구조)을  
**밖으로 끌어내는 동적 확장 언어**를 만든다.

Mathless는 “또 하나의 Pascal”이 아니라:

- 겉: 더 많은 개발자가 익숙한 표면 문법
- 속: Delphi/네이티브 실행 모델
- 배포: 소스 없는 네이티브 모듈
- 사용: 호스트 재컴파일 없이 복잡한 로직·상태를 교체

## 성공하면 생기는 일

1. Delphi 제품이 고객/내부/AI가 작성한 로직을 안전하게 확장할 수 있다.
2. C/C++/C# 호스트도 같은 모듈 형식을 로드할 수 있다.
3. 배포된 알고리즘을 소스 수준으로 읽기 어렵다.
4. AI가 타입 계약을 보고 모듈 코드를 생성·검증하기 쉽다.

## 성공이 아닌 것

- 범용 대중 언어가 TypeScript를 대체하는 것
- 브라우저 퍼스트 언어
- “완벽한 안티리버싱”
- 처음부터 모든 호스트 언어에서 동일한 DX

## 초기 한 문장 가치

> 호스트를 다시 빌드하지 않고도, 타입이 있는 복잡한 로직을 보호된 네이티브 모듈로 붙일 수 있다.

## 사용자

1차: Delphi/Windows 네이티브 제품 개발자 (확장·플러그인·비즈니스 룰)  
2차: C/C++ 네이티브 호스트 개발자  
3차: C# 호스트, 이후 필요 시 Python 바인딩

웹 개발자는 1차 고객이 아니다.
