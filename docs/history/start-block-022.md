> ### 2026-09-12 (3) 기준 — **전면 감사를 했다 (§9-33)**
>
> **기준선은 건강하다**: 네 게이트 `require`, **503 passed / 0 failed / 0 ignored, SKIPPED 0건**.
> 호스트 메모리 쓰기 **37곳 전수에 가드가 있고**, 적대적 입력 5종에 **패닉 0건**이다(§9-33 표).
>
> **결함 6건 중 넷은 고쳤다**(가드 구멍 하나 · 낡은 숫자 둘 · 근거 수준 오기 하나).
> **둘은 SPEC으로 냈고, 그것이 다음 한 걸음이다:**
>
> 1. [`SPEC-qualified-abi-version.md`](../slices/SPEC-qualified-abi-version.md) —
>    **링크하는 호스트가 ABI 버전을 모듈 하나에만 묻는다**(실측, §9-33.1). 지문에서 고친 것과 같은
>    모양이 버전에 남아 있다. **권고는 (A) 하지 않는다** — 지문 때는 대가가 0으로 측정됐지만
>    여기서는 export 3→4와 대외 문구 변경이다. **확인이 필요한 것은 고치는 방법이 아니라
>    고치지 않기로 하는 것이다.**
> 2. [`SPEC-module-name-length.md`](../slices/SPEC-module-name-length.md) —
>    컴파일러는 **70자 이름을 exit 0으로** 통과시키는데 참조 동적 호스트는 **66자부터 거부**한다.
>    **#215가 만든 결함이다.** 권고는 **(A) 컴파일러가 먼저 거부하고 호스트 버퍼가 그것을 유도**.
>
> ⚠ **둘 다 `DECISIONS.md`를 건드리지 않는다** — 파생 상세가 필요해지면 규칙 8대로 따로 받는다.
