## 1. 목표

함수 본문에 **지역 변수** `let NAME = EXPR`를 추가한다. 지역 변수는 **내부 전용**(생성 Rust의
`let` 바인딩)이며 **ABI에 노출되지 않는다** — export 집합·보호 프록시는 변하지 않는다. WBS가
예고한 "후속 변수(local) 도입"의 실체.

기준 함수:

```text
export fn discount2(price: f64, vip: bool) -> f64 {
  let rate = 0.9
  if vip { return price * rate }
  return price
}
```

## 2. 계약 (Contracts)

### 2.1 표면 `.mls`

- **`let NAME = EXPR`** — 종결자 없음(`return expr`와 일관). 타입은 **EXPR에서 추론**(DP-L1).
- 지역 변수는 **불변**(재대입 문 없음, DP-L4).
- **블록 스코프**(DP-L5): `let`은 자신이 속한 블록과 그 하위 블록에서만 보인다.

### 2.2 모듈 ABI — **변경 없음**

- 지역 변수는 생성 Rust의 `let x = …;`일 뿐 export 심볼이 아니다. `mlx_` 시그니처, 예약
  `ml_module_abi_version`, strip/no_std, export 집합 모두 **불변**. (수용 C 프록시 회귀 없음.)

### 2.3 스코프·규칙 (Grok 교차검토 반영)

- 지역 변수는 **자신의 `let` 이후**에만 스코프에 들어온다 → `let x = x`는 **use-before-def**로
  거부(타입체크는 RHS를 **먼저** 검사한 뒤 바인딩을 추가한다).
- **재선언·섀도잉 금지**(DP-L2): 지역 변수 이름이 **이미 보이는 이름**(파라미터, 또는 바깥 블록을
  포함한 스코프의 다른 지역 변수)과 겹치면 거부(안쪽 블록이 바깥 이름을 가리는 섀도잉도 금지).
- **예약어 검사**를 지역 변수 이름에도 적용(DP-L3, 전 대상 Rust/C/Pascal).
- **실패 가능 함수(`-> T!`)에서 `out_value`는 예약**(D17 out-param) — `let out_value`는 거부
  (기존 파라미터 가드를 지역 변수로 확장; Grok 지적: `let out_value`가 `*out_value =`를 가로챈다).
- **블록이 `let`으로 끝나면**(return/fail 없음) 기존 "모든 경로 return" 검사가 거부한다.
- **`if` 본문의 `let`은 그 블록에만** 유효 → `if` 밖에서 참조하면 **미정의 변수**로 거부(스코프가
  누출되지 않도록 typeck가 블록마다 중첩 스코프를 사용, Rust 블록 스코프와 일치).

## 3. 수용 기준 (측정 가능)

- **A. 컴파일:** `examples/discount2.mls`(지역 변수 사용) → `mlc build` → `discount2.dll`.
- **B. 로드·호출 (오라클):** `mlx_discount2(100,true)==90`, `(100,false)==100`, `abi==1`.
- **C. 보호 (D04/D05):** export = **정확히** `mlx_discount2` + `ml_module_abi_version`(지역 변수
  비유출). strip/no_std 유지 — 스칼라 슬라이스와 동일한 프록시.
- **부정(타입체크) 케이스:**
  - `let x = x` → use-before-def 거부
  - `let x = 1.0` 두 번, 또는 지역 변수 == 파라미터명 → 재선언 거부
  - 예약어 지역 변수명(예: `let type = 1.0`) → 거부
  - 실패 가능 함수의 `let out_value = …` → 거부
  - `if b { let r = 1.0 return r } return r` → 바깥 `return r`의 `r` 미정의 거부(안쪽 `let r`은
    그 `if` 블록에서만 유효; Grok 지적으로 예시 명확화)
- **양성 커버리지(Grok 권장):** `let`을 쓰는 실패 가능 함수(`-> f64!`)도 정상 컴파일·호출되고
  status/out-param 규약이 유지됨을 오라클로 1건 확인(지역 변수와 D17 lowering 상호작용 검증).
- **D. D14 게이트:** 지역 변수는 ABI 무관 → 이 슬라이스는 D14에 영향 없음(수용 D는 별개, BLOCKED).

## 4. 설계 제안 (DP — **확인됨**; 권장안 그대로 채택, PR #26으로 구현)

| DP | 선택지 | 권장(Grok) | 근거 |
|----|--------|-----------|------|
| **L1 타입** | 추론 전용 vs 선택적 `let x: f64 =` | **추론 전용** | 파라미터가 타입 계약을 담당; `: T`는 추가 문법(후속) |
| **L2 섀도잉** | 재선언·섀도잉 거부(이미 보이는 이름) vs 허용 | **재선언·섀도잉 거부** | 명확·단순; 섀도잉은 후속 |
| **L3 예약어 범위** | 전 대상(Rust/C/Pascal) vs Rust만 | **전 대상** | WBS 명시; 식별자 정책 일원화(내부 전용이라도) |
| **L4 가변성** | 불변 전용 vs `let mut` | **불변 전용** | 재대입 문이 없어 `mut`은 빈 표면 |
| **L5 스코프** | 블록 스코프(중첩) vs `if` 안 `let` 금지 | **블록 스코프** | Rust와 일치, 자연스러움; 금지안은 더 단순하나 제약 |

## 5. 범위 밖 / 미검증

- 재대입/가변 지역 변수(누산기 등) — 후속 "assign" 슬라이스(DP-L4 대안).
- 명시적 타입 표기(DP-L1 대안), 문자열/구조체 지역 변수(마샬링 슬라이스), 상수 폴딩.
- 어떤 항목도 측정 전까지 "확정/동작"으로 서술하지 않는다.
