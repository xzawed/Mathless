# GLOSSARY

> **여기 있는 것은 뜻 한 줄과 포인터뿐이다 — 값도, 개수도, 목록도 없다.**
> Grok이 이 문서를 넓히자는 제안을 검토하며 위험을 한 문장으로 짚었다: *"프로세스 정의를 여기
> 복사하면 그것을 소유한 문서에서 표류해, 용어집이 **낡은 두 번째 사본**이 된다."* 그것이 이
> 저장소가 2026-09-22 감사에서 반복해 본 실패다. 그래서 각 항목은 **무엇을 뜻하는지**만 고정하고
> **어디가 정본인지**를 가리킨다. 정본이 바뀌면 여기는 바뀌지 않아도 된다.

## 제품 — 소프트웨어가 하는 일

| 용어 | 뜻 | 정본 |
|------|-----|------|
| **Mathless** | 이 언어/프로젝트 이름 | `docs/VISION.md` |
| **Surface syntax** | 개발자가 작성하는 표면 문법 | `docs/LANGUAGE.md` |
| **Meaning / 내부 모델** | 타입·실행 의미. Object Pascal/네이티브에 가깝다 | `docs/LANGUAGE.md` |
| **IR** | 컴파일 중간 표현. **런타임 실행 포맷이 아니다** | `docs/ARCHITECTURE.md` |
| **C ABI** | 호스트와 모듈의 **1급 경계**. 언어별 바인딩은 그 위의 얇은 래퍼다 | `docs/HOST_ABI.md` |
| **Module** | 컴파일된, 로드 가능한 네이티브 라이브러리 | `docs/ARCHITECTURE.md` |
| **Host** | 모듈을 로드해 호출하는 애플리케이션 | `docs/HOST_ABI.md` |
| **`mlx_` / `ml_`** | export 네임스페이스. `mlx_`는 사용자 함수, `ml_`은 예약 심볼 | `runtime/ml_abi.h` |
| **지문 (interface fingerprint)** | 모듈의 **호스트 가시 계약**에서 계산한 64비트 값. 호스트가 로드 직후 자기가 빌드된 값과 대조해 다르면 거부한다. **무결성(P1)이 아니다** — 막는 것은 실수이지 공격이 아니다 | `docs/slices/SPEC-iface-hash.md` |
| **매니페스트 (`ml-iface/N`)** | 지문을 계산하는 입력이 되는, 규칙대로 만든 바이트열 | `docs/slices/SPEC-iface-hash.md` §2.1 |
| **드리프트 (drift)** | 호스트를 다시 빌드하지 않고 모듈만 바꿨을 때 계약이 어긋난 상태. 심볼은 그대로 해석되므로 **조용한 오답**이 될 수 있다 | `docs/slices/SPEC-iface-hash.md` §0.1 |
| **Q12 / caller-allocates** | 가변 길이 데이터의 소유권 규약 — **호스트가 버퍼와 용량을 주고 모듈이 채운다.** 모듈은 할당하지 않는다 | `docs/HOST_ABI.md` "가변 길이 데이터" |
| **프록시 (protection proxy)** | 보호를 **직접** 재지 못하므로 대신 재는 관측값(export 개수, 디버그 심볼 유무 등). **"리버싱 난이도"로 환산하지 않는다** | `docs/SECURITY.md` |
| **P0 / P1 / P2** | 보호 강도 단계 | `docs/SECURITY.md` |
| **Galapagos** | Delphi 생태계가 바깥 흐름과 단절된 상태를 가리키는 표현 | `docs/COMPETITIVE.md` |

## 프로세스 — 이 저장소가 일하는 방식

| 용어 | 뜻 | 정본 |
|------|-----|------|
| **슬라이스 (slice)** | SDD의 작업 단위. 기능 하나를 표면 문법부터 오라클 실측까지 **세로로 관통**해 끝낸다. phase와 다른 층이다 | `docs/slices/README.md` |
| **SPEC** | 슬라이스마다 구현 **전에** 쓰는 문서. 사용자 확인 없이는 구현을 시작하지 않는다 | `CLAUDE.md` "개발 방법론" |
| **DP-xx** | SPEC 안의 **설계 결정 항목**. 권고를 적고 사용자 확인을 받는다(접두 글자는 그 슬라이스의 것) | 각 SPEC의 "설계 결정" 절 |
| **수용 (acceptance) A·B·C…** | 측정 가능한 완료 기준. 문자는 그 SPEC 안에서만 뜻이 있다 | 각 SPEC의 "수용 기준" 절 |
| **게이트 (gate)** | 없으면 **skip이 아니라 실패**로 바꿀 수 있는 검사. 환경변수로 켠다 | `.github/workflows/ci.yml`의 `env:` |
| **오라클 (oracle)** | 컴파일러가 만든 모듈을 **밖에서** 로드해 값을 확인하는 Rust 테스트 하네스 | `hosts/rust-oracle/` |
| **코퍼스 (corpus)** | 게이트가 통째로 돌리는 예제 묶음. 게이트가 디렉터리를 열거해 **스스로 센다** | `examples/` |
| **골든 (golden)** | 생성 산출물을 고정한 파일. diff를 **읽고** 커밋한다 | `compiler/tests/golden/` |
| **핀 (pin) / needle** | 문서나 산출물의 한 문장을 기계가 붙잡는 방식(핀)과, 그때 찾는 문자열(needle) | `hosts/rust-oracle/tests/doc_claims.rs` |
| **E0 / E1 / E2** | 근거 수준 — 문서 정합 / 외부 출처 / **이 저장소에서 실제로 잰 것**. 주장마다 붙지 문단마다 붙지 않는다 | `CLAUDE.md` "실측 데이터 기반" |

## 확장자 — 가칭이다

- **`.mls`** 소스
- **`.mll`** 배포 모듈 — **⏳ 미구현**. 오늘 산출되는 것은 `.dll`이고 `.so`는 없다(D22 미개시)

둘 다 **확정 전**이다. 확정된 것처럼 서술하지 않는다.
