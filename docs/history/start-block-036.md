> ### 2026-09-15 (2) 기준 — **기록된 우회를 값으로 다시 쟀다 (§9-55)**
>
> 넷 다 깨끗했다(세율 상수 · 플래그 변수 · `out` 지역 변수 · Pascal 개명). **`out`은 컴파일러가
> 이미 강제하고 있었고**, Pascal 예약어 목록도 완전하다 — 그래서 지시어 쪽으로 넓혀
> **FPC 호스트가 `cdecl`·`external`·`name`이라는 이름의 파라미터를 부르는 것까지** 쟀다.
>
> ⚠ **다른 데서 하나 나왔다: i32 `+`·`-`·`*`가 조용히 wrap한다**(`2000000000+2000000000 =
> -294967296`). 동작은 **의도된 것이고 codegen에 명시**돼 있는데, **문서도 테스트도 값을 본 적이
> 없었다** — 기존 고정은 전부 생성 소스의 단어(`rust.contains("wrapping_mul")`)다. 같은 타입의
> `f64 as i32`는 **포화**한다고 적혀 있어서, 둘이 어긋난 채였다. §9-55.3.
>
> ⚠ **내 진단 셋 중 둘이 틀렸고 검증이 뒤집었다** — 원인이 `overflow-checks = false`라고 봤는데
> 아니다. 실물이 더 낫다(프로파일이 아니라 방출 식에 박혀 있다). §9-55.4.
>
