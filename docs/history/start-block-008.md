> ### 2026-09-07 (4) 기준 — **생성 `.pas`가 처음으로 컴파일됐다 (§9-11)**
>
> Delphi(`dcc64`)는 라이선스 제품이라 여기서 받을 수 없다. **Free Pascal 3.2.2**는 winget으로
> 받을 수 있어, 유닛 19개를 `-Mdelphi -Sew`로 컴파일하는 게이트를 넣었다. **첫 실행이 결함을
> 잡았다**: 지문 상수가 부호 있는 Int64로 타입돼 **19개 중 11개**가 range-check 경고를 냈다
> (값은 맞다 — 그것도 쟀다). `UInt64($...)` 한 토큰으로 고쳤고 골든 `.pas` 19줄만 움직였다.
>
> ⚠ **이것은 Delphi 게이트가 아니다.** `X1`은 그대로 열려 있고 유닛은 그대로 DRAFT다.
> 증명하는 것은 C++ 게이트와 같은 종류 — **텍스트가 유효한가**까지다.
