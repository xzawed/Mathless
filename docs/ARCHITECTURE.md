# ARCHITECTURE

> **이 문서는 의도한 설계를 현재형으로 기술한다. 전부 구현된 것은 아니다.**
> 오늘 실제로 동작하는 범위는 `docs/LANGUAGE.md`(언어 표면)와 `docs/STATUS.md`(실측 상태)가 정본이며,
> 아직 만들지 않은 항목에는 **⏳ 미구현**을 붙였다. 설계 기록으로서의 값을 유지하려고 문장을 미래형으로
> 바꾸지는 않았다.

## 원칙

개발자가 보는 계층과 실행 계층을 분리한다.  
변환은 컴파일 타임에만 일어난다. 실행 시점에는 네이티브 코드만 남긴다.

```
[표면 문법 소스 .mls]
        │  parse / typecheck
        ▼
[내부 IR]
        │  lower to native backend
        ▼
[네이티브 오브젝트]
        │  link + optional protect
        ▼
[배포 모듈 .dll  (⏳ .so/ELF·.mll 컨테이너는 미구현)]
        │  C ABI
        ▼
[호스트 앱: C ✅ 실측 / Delphi · C++ · C# P/Invoke ⏳ 미검증]
```

파일 확장자는 가칭이다. 확정 전.

## 컴파일 파이프라인

1. **Lex / Parse**  
   표면 문법 → AST
2. **Resolve / Typecheck**  
   강한 정적 타입. 호스트가 제공한 인터페이스 정의도 여기서 검증(**⏳ 미구현** — 호스트 인터페이스 입력이 아직 없다)
3. **IR**  
   언어 중립에 가깝되, 네이티브/Delphi 실행 모델(값 타입, 명시적 수명 후보)을 표현할 수 있어야 함
4. **Codegen**  
   1차 현실 후보: LLVM 또는 기존 네이티브 툴체인에 lowering  
   “내부가 Delphi 방식”이 Delphi 컴파일러를 반드시 호출한다는 뜻은 아님.  
   **의미 모델**이 Object Pascal/네이티브에 가깝다는 뜻이다.
5. **Packaging**  
   export 테이블, 버전 심볼. 인터페이스 메타는 **⏳ 미구현**
6. **Protect (배포 빌드만)**  
   strip, 심볼 제거, 이후 단계적 강화

## 런타임에 존재하는 것

- 로더 — 오늘은 **호스트 쪽**이다(`LoadLibrary`/`GetProcAddress`). 얇은 C 런타임은 **⏳ 미구현**
- C ABI 호출 규약
- 선택적 무결성 검사 — **⏳ 미구현**(P1, `SECURITY.md`)
- 에러 코드 규약(D17, 구현됨). 모듈용 할당자 등 그 밖의 런타임 지원은 **⏳ 미구현**

런타임에 존재하지 말아야 할 것:

- 소스 파서
- 표면 문법 인터프리터
- 일반 eval

## 모듈과 호스트

모듈은 플러그인이다.

- 호스트가 모듈을 `load`
- 모듈 export를 호스트가 호출한다. 반대 방향(호스트가 허용한 함수/객체를 모듈에 넘기는 것)은 **⏳ 미구현**
- 모듈 교체 = 파일 교체 + 재로드. 호스트 재빌드 없음

## 개발 vs 배포

| | 개발 | 배포 |
|--|------|------|
| 소스 | 로컬에만 | 없음 |
| 심볼/디버그 | 가능 | 제거 |
| 보호 | 약하거나 없음 | 단계적 강화 |
| 피드백 | 빠른 컴파일, 명확한 타입 에러 | 실행과 무결성 |

## 웹

브라우저에서 DLL을 실행하지 않는다.  
웹이 필요해지면 **별도 WASM 타깃**을 추가하는 것이지, 기본 모델을 WASM으로 바꾸지 않는다.

## 구현 시 권장 경계

- `compiler/`: 프론트엔드 + IR
- `backend/`: 네이티브 codegen
- `runtime/`: 얇은 C ABI 런타임
- `host/delphi`, `host/c`: 바인딩
- `packager/`: 모듈 포맷

MVP는 compiler 최소 + C ABI + Delphi 또는 C 호스트 하나면 충분하다.
