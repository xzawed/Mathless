## 9. 새 세션 시작 절차

1. 이 문서 → `README.md`(문서 지도) → `docs/slices/README.md`(슬라이스 색인) → `CLAUDE.md`(규칙).
2. 실측부터 한다 — **CI가 요구하는 게이트 셋을 전부 건다.** 하나만 걸면 나머지는 skip되고
   스위트는 그대로 초록이라, Pascal 쪽 회귀를 못 본다(*a skipped gate is not a passed gate*).

   ```powershell
   $env:MATHLESS_GATE_D="require"; $env:MATHLESS_GATE_FPC="require"; $env:MATHLESS_GATE_FPC_HOST="require"
   cargo test --workspace --locked
   ```

   Git Bash에서는 한 줄로:
   `MATHLESS_GATE_D=require MATHLESS_GATE_FPC=require MATHLESS_GATE_FPC_HOST=require cargo test --workspace --locked`.
   목록의 정본은 `.github/workflows/ci.yml`의 `env:`다.
3. **바로 아래 "▶ 여기서 시작한다" 블록으로 간다** — 그 한 블록이 오늘의 착수 지점과 추천 순서를
   담고 있다. 요약(2026-09-05 밤): **N·D 표도 §9-A도 비었고, 전수 코드 감사(§9-4)도 끝났다** —
   확인된 58건이 13 PR로 닫혔거나 실측으로 닫혔다. **남은 착수 대기가 하나도 없다.** 그래서 다음은
   **새 표면**(언어 슬라이스)이거나, 외부 조건(X1~X3) · 재현 안 된 것(R1~R3) ·
   §5-5의 남은 부채다.
   > **2026-09-11 정정 — 이 줄은 DP-H3(b)를 후보로 불렀다.** 그것은 같은 날(2026-09-05 낮)
   > **하지 않는다로 닫혔다**(#141, `SPEC-symbol-embedded-hash.md`). 아래 ▶ 블록의 그날 항목이
   > 그렇게 적고 있는데 이 요약만 낡아 있었다 — **한 문서 안에서 닫힌 것을 후보로 부르는 형태**이고,
   > §7-1이 세 번 데였다고 기록한 그 모양이다.
   > 표는 번호로 고정돼 있다(N·D·X·R). 닫힌 행도 지우지 않고 ✅로 남기므로, **✅가 아닌 행만**
   > 훑으면 열린 것이 나온다.
   >
   > **2026-09-24 — 같은 요약이 두 번째로 낡았다.** 거기 든 *재현 안 된 것(R1~R3)* 은 **셋 다 닫혔고**
