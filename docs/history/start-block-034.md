> ### 2026-09-13 (9) 기준 — **§7의 도구가 생겼다: `mlprobe` (§9-49)**
>
> *"스니펫 → 빌드 → 로드 → 호출 → **값 출력**"* 이 이제 한 줄이다:
>
> ```
> cargo run -p mlc --bin mlprobe -- --src '<소스>' <함수> <인자>...
> ```
>
> **값을 재는 것이 컴파일을 확인하는 것만큼 싸졌다.** §7이 그 비대칭 때문에 *"컴파일되고,
> 그럴듯하고, 틀린"* 결함이 네 번 지나갔다고 적은 그것이다. 모든 ABI 모양을 실측으로 확인했다
> (스칼라 · 배열 입력 · `T!` · Q12 `string!` · 배열 반환 · 선언된 `out` · 음수 status).
>
> ⚠ **이 머신에서 `probe.dll`은 만들 수 없다**(보안 에이전트, `os error 5`). 컴파일러 문제가
> 아니고 이름 문제다 — §9-49.2.
>
> ⚠ **§5-5.7을 내가 세 번째로 냈다**(도구가 27개를 남겼다). 가드가 `tests/`만 봤기 때문이고,
> 이제 `compiler/src/bin`까지 본다 — §9-49.3.
>
