### 9-30. 지문 심볼 개명을 **프로토타입으로 재고 폐기했다** (2026-09-12, E2) — SPEC은 확인 대기

§7-4가 찾은 결함(링크된 호스트가 지문 하나만 본다)을 **고칠지 말지 논증으로 정하지 않았다.**
`SPEC-symbol-embedded-hash`가 쓴 방식 그대로 — **실제로 구현해 보고 재고, 트리에서 지웠다.**

| # | 무엇 | 결과 |
|---|---|---|
| M1 | 고쳐지는가 | ✅ 두 모듈 링크 호스트가 **양쪽 지문을 다 본다**(이전 `1 0`) |
| M4 | 보호 프록시 대가 | **0** — export **3개 그대로**, **9,728 B 그대로** |
| M2 | 옛 호스트 + 새 모듈(소스) | 컴파일 실패 `C2065` + 호스트 자신의 `static_assert` |
| M3 | 새 호스트 + 옛 모듈(링크) | 링크 실패 `LNK2019` |
| M5 | **컴파일된** 옛 호스트 + 새 모듈(런타임) | `a reserved symbol is missing`, exit 3 |

**M4가 결정적이었다.** 예상했던 유일한 실질 대가(export 표면 = D05의 P0 프록시)가 **0으로 측정**됐다.
남은 대가는 플래그 데이 하나이고 **세 경로 전부 시끄럽다** — 이 저장소가 반복해서 고른 쪽이다.

**두 번 가설이 반증됐고, 둘 다 적어 뒀다:**

1. **ABI 버전 bump이 메시지를 개선할 것** → **아니다.** `gate()`가 두 심볼을 **동시에 조회한 뒤**
   `NULL`을 먼저 검사하므로, 옛 호스트가 받는 문장은 올리든 말든 같다(DP-Q4). 코드를 읽고 알았다.
2. **`ml_module_abi_version`도 같이 개명** → **아니다.** 값이 컴파일러 상수라 충돌이 무해하고,
   **D18의 부트스트랩**이다 — 개명하면 "너는 어떤 ABI냐"를 물을 수단 자체가 사라진다.
   검토는 처음에 둘 다 개명을 권했고, 이 구분을 주자 **정제형으로 바꿨다.**

**검토가 SPEC의 과장 둘을 잡았다**: `0xC0000139`의 부재를 실측인 것처럼 적은 것(잰 것은 이 개명의
플래그 데이다)과, 혼합 컴파일러 버전 건이 논증인데 측정처럼 읽힌 것(재려면 컴파일러 두 벌이 필요하다).

**M5는 검토가 "그건 안 쟀다"고 짚어서 추가로 쟀다** — 실제 사용자가 만날 유일한 런타임 경우다.
