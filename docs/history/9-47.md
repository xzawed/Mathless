### 9-47. 스팬 비교 구현 (2026-09-13, E2) — **§7이 못 쓴 규칙을 §7이 찾아서 고쳤다**

사용자가 DP-C1~C5를 확인했고 구현했다. **§9-46의 R2가 이제 컴파일된다** — 그리고 그 규칙 자체가
`examples/account.mls`의 `is_kookmin`으로 들어가 **C 호스트 게이트에서 돈다.**

```
byte_slice(acct, 0, 3) == "004"    →  status 0, true   (소스 10바이트, 스팬 3바이트)
```

#### 9-47.1 위험이 **둘로 갈렸다** — SPEC의 서술을 정정한다

SPEC §5.2는 *"접미사 오답"* 을 수용 C가 막는다고 적었다. **두 방식으로 깨 보니 갈렸다:**

| 무엇을 뺐나 | 결과 |
|---|---|
| 비교 lowering**만** | **`unreachable!` 패닉** — 조용하지 않다. `ByteSlice`를 식으로 낼 길이 없다 |
| 비교 lowering **+** `ByteSlice` 팔에 맨 포인터 | **조용한 오답 `(0, false)`**(진실 `(0, true)`), status 0 |

**즉 두 보호가 겹친다.** `emit_expr`의 `unreachable!`이 첫 번째이고, 그것을 채우는 순간
**수용 C가 유일한 방어**가 된다. 사전 검증이 이 구조를 미리 짚었고, 실측이 그 말을 확인했다.

#### 9-47.2 사전 검증이 **SPEC 자신의 코드 조각**에서 버그를 잡았다

초안 §2.5가 `return -2;`를 적었는데 그것은 **`StringOut` 형태**다. 이 슬라이스의 동기가 되는
예제는 `-> bool!`, 즉 `RetAbi::Fallible`이고 본문이 `Result<bool, i32>`를 돌려준다 —
**`return Err(-2);`** 여야 한다. 그대로 베꼈으면 **생성 Rust가 컴파일되지 않았다.**

생성 코드 실측:

```rust
fn ml_fn_is_kookmin(acct: *const u8) -> Result<bool, i32> {
    if (ml_slen(acct) < 3i32) { return Err(1); }
    return Ok({ let __ss = acct; let __sf = 0i32;
                let __sl = ml_sublen(__ss, __sf, 3i32);
                if __sl < 0 { return Err(-2); }
                ml_subeq(__ss, __sf, __sl, b"004\0".as_ptr()) });
}
```

> **사전 검증이 값을 한 네 번째다**(#223 둘 · #229 · #234).

#### 9-47.3 죽은 헬퍼 둘을 만들었다가 실측이 잡았다

첫 구현은 스팬을 비교하는 **모든 모듈에 `ml_streq`를 죽은 채로** 넣었다 — `compares_strings`가
스팬 비교까지 세고 있었기 때문이다. `ml_wsub`도 비교만 하는 모듈에서 죽어 있었다.

`the_helper_is_only_emitted_when_a_comparison_exists`가 적어 둔 그 규칙이다 —
*"넓힌 게이트는 좁힌 게이트만큼 쉽게 과잉 방출한다."* 셋을 각자 게이트로 갈랐고
(§9-40이 `emit_slen_helper`를 가른 것과 같은 이유), **골든 diff가 +40줄에서 +30줄로** 줄었다.

#### 9-47.4 묻지 않은 것이 하나 더 — `s`가 두 번 방출되고 있었다

검증: *"`s` is emitted twice (`ml_sublen` and `ml_subeq`) while `from` is bound once."*
오늘 `s`는 파라미터나 리터럴뿐이라 **대가는 0이다.** 그래도 묶었다 — 연결 emitter가
**같은 실수의 다른 판본을 실측**했고(`ml_fn_score(…)`가 패스마다 한 번씩), 그 주석이
*"두 번 방출하는 것이 곧 두 읽기가 갈라질 수 있는 기제"* 라고 적어 뒀기 때문이다.

그리고 같은 검증이 **스팬 대 스팬이 `unreachable!`에 닿는다**고 짚었다 — 타입체커가 DP-C5로
막으므로 소스에서 도달 불가이고, 그래서 그 거부 테스트가 **메시지까지** 단언하도록 고쳤다.
**타입체커의 거부가 그 팔을 도달 불가로 유지하는 유일한 것이다.**
