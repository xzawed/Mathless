# GLOSSARY

| 용어 | 의미 |
|------|------|
| Mathless | 이 언어/프로젝트 이름 |
| Surface syntax | 개발자가 작성하는 문법 |
| Meaning / 내부 모델 | 타입·실행 의미. Delphi/네이티브에 가깝게 |
| IR | 컴파일 중간 표현. 런타임 실행 포맷이 아님 |
| C ABI | 호스트와 모듈의 1급 경계 |
| Module | 컴파일된 로드 가능 네이티브 라이브러리 |
| Host | 모듈을 로드하는 애플리케이션 |
| P0/P1/P2 | 보호 강도 단계 |
| Galapagos | Delphi 생태계가 바깥 흐름과 단절된 상태를 가리키는 표현 |

가칭 확장자:

- `.mls` 소스
- `.mll` 배포 모듈 (또는 `.dll`/`.so` 직접)

확정 전이다.
